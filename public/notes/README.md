# 放置 GoodNotes PDF 的資料夾

你不需要修改任何程式。請直接把下面四個資料夾放進這個 `notes` 資料夾：

```text
public/notes/
├── 大一上/
├── 大一下/
├── 大二上/
└── 大二下/
```

每個學期資料夾內，再放對應的課程資料夾與 PDF，例如：

```text
public/notes/大一上/
├── 微積分/
│   └── 極限與微分.pdf
└── 程式設計/
    └── Python 基礎.pdf
```

網站會自動讀取所有 PDF：

- 學期資料夾名稱要完全是「大一上」、「大一下」、「大二上」或「大二下」。
- 課程資料夾名稱會自動成為網站上的課程名稱。
- PDF 檔案名稱會自動成為筆記標題。
- 放好後，將本機預覽關掉再重新執行 `npm run dev`；未來發布網站時，執行 `npm run build` 也會自動更新。
